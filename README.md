# Simulation-Based Validation of an Acoustic-Energy Attenuation Model for AI-Driven Pipeline Leak Detection and Localization

This repository contains the simulation code and analysis notebooks for
the paper *"Simulation-Based Validation of an Acoustic-Energy
Attenuation Model for AI-Driven Water Pipeline Leak Detection and
Localization"* (under review). It reproduces every table and figure in
the paper from synthetic data, with fixed random seeds for full
reproducibility.

> **Note.** Author and affiliation information is omitted to preserve
> double-blind review. This notice will be updated upon acceptance.

## Overview

The study generates physics-based synthetic leak acoustic signals in
which an exponential attenuation model is embedded, so that the true
leak position is known and localization error can be quantified. The
pipeline (1) generates signals, (2) extracts the least-noisy segment and
converts it to spectrograms with data augmentation, (3) classifies
leak / consumption / other with a lightweight neural network, and (4)
decides same-pipe origin via spectrogram correlation and localizes the
leak using two attenuation models (exponential vs energy-distance
inverse), followed by sensitivity analyses.

## How to reproduce

Run the notebooks in order; each writes its outputs to `data/` or
`results/` and the later notebooks depend on the earlier ones.

1. `notebooks/01_signal_generation.ipynb` — generate synthetic signals
   → `data/signals.npz`, `data/labels.csv`
2. `notebooks/02_preprocessing_spectrogram.ipynb` — segment extraction,
   spectrograms, augmentation, absolute pattern energies
   → `data/spectrograms.npz`
3. `notebooks/03_cnn_classification.ipynb` — classifier training,
   evaluation, and noise-robustness experiment
   → classification and robustness tables/figures
4. `notebooks/04_localization.ipynb` — same-pipe decision and leak
   localization with sensitivity analyses
   → localization and sensitivity tables/figures

For a clean run, restart the kernel and execute all cells top to bottom
in each notebook, in the order above.

## Reproducibility

- All stochastic steps use a fixed seed (`SEED = 42`).
- Figures are saved as both PNG and PDF at 600 dpi in grayscale.
- The `data/` directory is regenerated by the notebooks and is not
  tracked in version control.

## Outputs

**Tables** (`results/tables/`): `classification_report.csv`,
`confusion_matrix.csv`, `robustness_noise.csv`,
`same_pipe_decision.csv`, `localization_error.csv`,
`sensitivity_alpha.csv`, `sensitivity_snr.csv`.

**Figures** (`results/figures/`): example waveforms, spectrograms, and
augmentation; confusion matrix; training curve; robustness curve;
same-pipe ROC and score distributions; localization scatter; error
distribution; alpha and SNR sensitivity.
